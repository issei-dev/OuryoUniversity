FACULTY OF COMMUNICATION

コミュニケーション学部

人と社会を、つなぐ力を学ぶ。

Introduction

学部紹介

コミュニケーション学部では、メディアと心理の両面から「人と人、人と社会のつながり」を学びます。情報があふれる現代社会において求められる、的確に発信する力と、人の心を深く理解する力を実践的に養成。多様な人々と関わり、社会のなかで信頼関係を築きながら活躍できる女性を育てます。

メディアコミュニケーション学科心理コミュニケーション学科

Features

コミュニケーション学部の特徴

📱

FEATURE 01

メディア実習

映像制作やSNS運用など、実際に手を動かしながらメディアの仕組みを学びます。情報を「受け取る」だけでなく「つくり、発信する」力を実践的に身につけます。

🧠

FEATURE 02

心理学の基礎

人の心の動きや行動の仕組みを科学的に学びます。心理学の知識は、人間関係やマーケティングなど、社会のあらゆる場面で役立つ実践的な教養となります。

🎤

FEATURE 03

プレゼン・発信力

自分の考えを的確に伝えるプレゼンテーション力を、実践を通じて磨きます。論理的に組み立て、相手に伝わる表現で発信する力を養います。

Points

学びの3つのポイント

POINT 01

💻

映像・SNS制作

実際のコンテンツ制作を通じて、メディアを使いこなす実践的なスキルを習得します。

POINT 02

🔍

心理データ分析

アンケートや実験を通じて、人の心理をデータから読み解く分析力を養います。

POINT 03

🗣

実践プロジェクト

チームで取り組む実践型プロジェクトで、協働力と発信力を実社会さながらに鍛えます。
