生活科学部

暮らしを彩り、健康を支える。

Introduction

学部紹介

生活科学部では、衣・食を科学的に学び、人々の豊かな暮らしと健康を支える専門家を育成します。デザインや栄養の専門知識と実践的なスキルを、充実した実習設備のなかで習得。日々の暮らしに根ざした学びを通じて、人々のQOL（生活の質）の向上に貢献できる、感性と専門性を兼ね備えた女性を育てます。

被服デザイン学科食物栄養学科

Features

生活科学部の特徴

👗

FEATURE 01

デザイン・縫製実習

企画からデザイン、縫製までを一貫して学べる充実した実習環境。自分の手で作品を生み出す経験を通じて、ファッション業界で活きる実践力と表現力を養います。

🍳

FEATURE 02

栄養・調理実習

栄養学の知識と調理技術を、実習を通じて実践的に習得。食を通じて人々の健康を支える、栄養士としての確かな専門性を身につけます。

🔬

FEATURE 03

生活科学の探究

衣食住を科学的な視点から探究し、より良い暮らしのあり方を研究します。生活に根ざした学びは、現代社会の課題解決にもつながる実践的な力となります。

Points

学びの3つのポイント

POINT 01

✂️

作品制作・展示

学びの成果を作品として形にし、展示会で発表。創作の喜びと達成感を実感できます。

POINT 02

🥗

栄養士資格

栄養士資格の取得に直結したカリキュラムで、食の専門家への道を確実にサポートします。

POINT 03

🏭

業界連携

アパレル・食品業界との連携を通じて、現場のニーズに触れる実践的な学びを得られます。

Student's Voice

先輩の声

👩‍🎨

橋本 さくら さん

被服デザイン学科 4年／天府都立白金ヶ丘高校 出身

作品づくりに没頭できる環境です。

デザインから縫製まで一貫して学べるので、頭の中のイメージを自分の手で形にする喜びを毎日感じています。実習設備が整っていて、納得いくまで作品づくりに打ち込めるのが魅力です。展示会で自分の作品を発表できたことは大きな自信になりました。将来はアパレル業界で活躍したいです。

👩‍🍳

山田 芽依 さん

食物栄養学科 3年／桜陵女子高校 出身

栄養の知識が暮らしに直結します。

栄養学を学ぶことで、食事が体や健康にどう影響するのかを科学的に理解できるようになりました。調理実習も多く、知識と技術の両方を身につけられます。学んだことが日々の生活にすぐ役立つのも楽しいです。栄養士として、人々の健康を食から支える仕事に就きたいと考えています。
